# Deep refactor Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bring Shakedown's Rust core, React UI, kits/integrations and SDK to a top-tier standard (modular, DRY,
typed, small units) without changing behaviour or look, and fix the gateway's missing token check.

**Architecture:** Three tracks with disjoint files. Track R (Rust core: `core/crates/shaked`, `core/crates/parts`),
Track U (`ui/src`), Track K (`kits/`, `integrations/`, `benchmarks/`, `sdk/python`). R and K both compile Rust, so
they run one after the other on branch `factory` (worktree `.worktrees/factory`); U runs at the same time on
branch `factory-ui` (worktree `.worktrees/factory-ui`) and is merged into `factory` at the end. Each task is a
series of small commits; every commit keeps the track's gate green.

**Tech Stack:** Rust (axum, tokio, tokio-postgres, serde), React 18 + TypeScript + Vite + vitest + Tailwind,
Python 3 (httpx, pydantic), uv.

**Spec:** `docs/superpowers/specs/2026-11-19-software-factory-design.md` (Goal 1). The three audits that define
the targets are reproduced in the appendices; their file:line references are the starting points.

## Global Constraints

- Behaviour-preserving. Public HTTP API paths, JSON shapes, event payload JSON, error message strings, protocol
  messages, UI text and look stay byte-identical. Tests assert on strings; never edit an assertion to make a
  refactor pass, except to update an import path or a renamed internal symbol.
- Gate per commit — Track R: in `core/`, `cargo clippy --workspace --all-targets -- -D warnings` and
  `cargo test --workspace --no-fail-fast` (Postgres for tests: container `deploy-pg-1` on 127.0.0.1:5544; start
  with `docker start deploy-pg-1` if refused). Track K: the same two commands at the repo root, plus
  `uv run --all-extras pytest -q` in `sdk/python` and `uv run pytest -q` in each Python package touched.
  Track U: in `ui/`, `npx tsc -b` and `npx vitest run --maxWorkers=1` (`--minWorkers` is not a valid flag).
- Shared machine: `CARGO_BUILD_JOBS=2`, `CARGO_PROFILE_DEV_DEBUG=0`; never run two cargo builds at once; vitest
  one worker. Redirect long output to a file and read its tail.
- clippy caps functions at 30 lines (`too_many_lines` with `-D warnings`).
- New dependency allowed: `thiserror` (Ruling: de facto standard in top Rust codebases; removes seven hand-written
  `Display` impls — cost if wrong: one more crate). No other new dependencies without a ledger ruling.
- `#[serde(default)]` on every field of a newly typed persisted payload, so runs recorded before the change read.
- No hardcoded domain data: data moved out of code goes to the package's data files.
- Commit messages: plain sentences in the repo's style (see `git log`), ending with the attribution line given
  in the session. Do not push. Do not merge to `main`.
- Do not rename `shakedown`/`SHAKEDOWN_*` identifiers, storage keys, crate names or `/api/suites` paths (a later rename
  owns those). Keep the `/suites/*` and `/history` UI redirects (Ruling: old links in videos and docs keep
  working — cost if wrong: four dead routes).

## Review Focus

1. Error precedence on API routes (409 vs 400 vs 415/403 vs 507) after extractors replace hand parsing: a request
   wrong in several ways must get the same status as before.
2. Old recorded runs (payloads missing keys, older `RunStart` shapes) still load, fork and render in the UI.
3. Run-start paths keep their quirks: `claim_external` returns `Err` after `slot_failed` while `start_builtin`
   returns `Ok(None)`; suite external runs never apply `max_cost_usd`; the API validates before the disk check.
4. UI fetch hooks: a stale response from a previous id never overwrites the current one; a failed poll keeps the
   last value (`usePolled`'s rule); streamed branch events still merge.
5. Integrations restarted mid-run (`.live/<id>.json` records) still save, inspect and stop their instances.
