# Plans, specs and research

The plans, specs, research notes and mockups in this folder are historical records: they are kept as they
were written and are not updated when the code changes.

On 2026-11-19 the service `arenad` was renamed `shaked` (crate `core/crates/shaked`) and the Python SDK `arena`
(`arena-sdk`, class `Arena`) was renamed `shakedown` (class `Shakedown`). Records written before that date use the
old names; the old names still work ([Old names](../../README.md#old-names)).
