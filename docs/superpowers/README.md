# Plans, specs and research

This folder keeps the plans, specs, research notes and mockups written while Shakedown was built. They are
historical records. They stay as written and are not updated when the code changes, so they can describe
designs that changed or were never built.

For how Shakedown works today, read the developer docs in [docs/](..) and the user guide at
[docs.coppertide.ai](https://docs.coppertide.ai). The code decides where a record and the code disagree.

| Folder | What it holds |
|---|---|
| `specs/` | Design specs, one per feature, named by date |
| `plans/` | Implementation plans that followed the specs |
| `research/` | Research notes |
| `mockups/` | UI mockups |
